
# Train Schedule Analysis and Interactive Route Enquiry System

A Python-based railway timetable analysis project developed during my internship at **Sysslan IT Solutions**.

## Project Overview

This project analyzes railway timetable data to identify train routes, station service patterns, journey durations, and data quality issues. It also includes an interactive route enquiry system that allows users to search for trains between selected source and destination stations.

## Key Features

- Dataset exploration and statistical overview
- Data cleaning and preprocessing
- Time and journey duration analysis, including midnight crossings
- Data quality checks and validation
- Exploratory data analysis and visualizations
- Advanced analysis using pivot tables and cross-tabulations
- Interactive train route enquiry
- Intermediate station and journey duration details
- Search results sorting, pagination, and export

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab
- IPyWidgets

## Project Workflow

1. Dataset exploration
2. Data cleaning and preprocessing
3. Data quality validation
4. Exploratory data analysis
5. Advanced statistical analysis
6. Interactive route enquiry

## Dataset Insights

- 186,074 timetable records analyzed
- 11,113 distinct train numbers
- 8,147 station codes
- 11,102 reliable journey duration records
- 2,537 journeys crossing midnight

## Project Limitations

This project uses static timetable data. It does not provide live train tracking, real-time delays, fares, or current running status.

## How to Run

1. Clone this repository.
2. Install the required Python packages.
3. Open the Jupyter Notebook in Google Colab or a local Jupyter environment.
4. Provide the permitted dataset file when prompted.
5. Run the notebook cells in sequence.
